# 專案目標與開發指南

## 1. 專案概述

**主要目標：** 開發一個命令列介面（CLI）應用程式。

**核心功能：** 讀取指定的 CSV 檔案，根據其內容建立一個樞紐分析表，並將結果儲存為 Excel 檔案。

---

## 2. 執行與規格

*   **工作目錄：** `實際案例4` (所有操作皆以此資料夾為根目錄)
*   **主要語言：** Python
*   **預期執行指令：**
    ```bash
    python app.py --csv data.csv --excel 2025_07_05.xlsx
    ```
*   **專案結構：**
    *   `app.py`: 應用程式主入口，負責處理命令列參數及核心邏輯。

---

## 3. AI 助理開發準則

*   **任務管理:**
    1.  請嚴格遵循 `.gemini/todolist1.md` 檔案中定義的任務清單。
    2.  **依序執行** 標示為 `[ ]` (未完成) 的任務。標示為 `[x]` 的任務表示已完成，請勿重複執行。
    3.  在開始執行一項新任務前，請先說明「現在要開始進行...任務」。
    4.  每完成一項任務，**必須** 將 `.gemini/todolist1.md` 中對應的 `[ ]` 更新為 `[x]`。

*   **程式碼撰寫要求:**
    *   所有 Python 的函式（function）、類別（class）和屬性（property）都必須包含簡潔明瞭的 docstring 註解，說明其用途。

*   **溝通語言:**
    *   請使用**繁體中文**進行所有回覆。
    *   請勿修改或翻譯程式碼、變數名稱或檔案名稱。
